EDGE TELEMATICS — DEMARRAGE DANS VS CODE

1. Ouvrir ce dossier dans VS Code.
2. Ouvrir Terminal > New Terminal.
3. Lancer une seule fois :

   .\INSTALLER.bat

4. Demonstration de resilience :

   .\LANCER_DEMO_CRISE.bat

5. Six tests lies a la crise :

   .\LANCER_TESTS_CRISE.bat

6. Tous les tests :

   .\LANCER_TESTS.bat

7. Demonstration locale de la chaine CI/CD :

   .\DEMO_CI_CD.cmd

8. Build et staging seuls :

   .\LANCER_LIVRAISON.bat

Les mesures sont traitees une par une. Seules les alertes critiques sont conservees dans SQLite.
